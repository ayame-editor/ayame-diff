# マージと調整

ローカル GUI は、既定ではどちらの入力も変更せず、比較結果から新しいマージ済み
ファイルを作成できます。

## テキスト

テキスト比較後、各ハンクに **左を採用** と **右を採用** のトグルが表示されます。
採用済みの側をもう一度クリックすると解除されるため、選択と解除は同じ操作で、
押下状態が現在何を採用しているかを示します。両方の側をオンにすると両方の寄与を
採用し、左→右の順に連結します。結果全体には
**すべて左** または **すべて右** を使います。元に戻す・やり直しはハンク選択の
スナップショットだけを保存するため、大きなソースファイルをブラウザ履歴へ複製しません。
`Alt+Left` と `Alt+Right` で現在のハンクの側を切り替え、`Alt+Up` / `Alt+Down` で移動し、`Ctrl+Shift+S` でマージ結果を保存します。3-way の結果では `Alt+B` が BASE、`Alt+A` が両方を保持し、`F8` / `Shift+F8` はコンフリクトだけを辿り、`Alt+Shift+A` で採用のたびに次の未解決コンフリクトへ自動移動します（#277）。

3-way 比較では各競合に **左を採用**・**ベースを採用**・**右を採用** のトグルが
表示されます。採用した寄与はベース→左→右の固定順で連結されるため、「左＋右」は
左の内容の後に右の内容が続きます（クリックした順序には依存しません）。

保存時は完全な差分を再計算し、変更のない範囲と選択した範囲を一時的な同階層
ファイルへストリーミングします。一時ファイルをフラッシュしてからアトミックに
置換します。LF/CRLF と末尾改行の状態は各範囲で選択したソースに従います。
UTF-8 以外からデコードした入力は UTF-8 で保存します。

未解決の差分が残った状態で保存する前には、マージパネルが各差分を種類と位置つきで
一覧表示し、**未解決箇所へ移動** で先頭へジャンプできます。**未解決の解決先** では、
そのまま保存する場合の扱いを選べます。

- **left** / **right** — 残りの差分をその側で解決します。
- **コンフリクトマーカーを残す** — 標準の `<<<<<<< LEFT` / `=======` /
  `>>>>>>> RIGHT` を書き出し、後工程で解決できるようにします。

保存結果はどちらだったかを正直に示します。暗黙に側を選んだ場合やマーカーが残る
場合はその旨を報告し、競合のないクリーンなマージとしては表示しません。

## CSV / TSV

各論理キー差分には、内容から導出した安定 ID があります。CHANGED の組には左右の
トグルが表示され、両方をオンにすると両方の行を保持し、左→右の順に出力します。
LEFT_ONLY / RIGHT_ONLY 行は片側にしか内容がないため、トグルは連結ではなくその行の
保持/削除を意味します（従来と同じ保持/削除の判断です）。保存時はメモリ有界の
分割・ソート処理を再実行し、同一行を含む完全な、キー順に整列した CSV または
TSV を出力します。メモリに保持するのは安定した選択マップだけです。

出力区切り文字はファイル名に従います。`.csv` / `.csv.gz` はカンマ、それ以外は
タブです。引用は標準 CSV 規則で書き出します。

## 安全規則

- 未解決差分は既定で保存を止めます。保存前にマージパネルが一覧表示し、警告を
  受け入れた場合は **未解決の解決先**（左 / 右 / コンフリクトマーカー）で選んだ
  扱いで保存します。常に左側だった従来の挙動は既定ではなくなりました。
- 既定では新しい出力パスへアトミックに書き込みます。
- どちらかの入力と同じ出力パスは、**入力を上書き**を有効にして二度目の破壊的確認を受け入れない限り拒否します。**影響をプレビュー**（または保存時の確認）は、書き込む出力と、上書きされる比較対象の入力を一覧してから実行します。
- 拒否、キャンセル、失敗した操作は両入力を変更せず、不完全な出力も公開しません。
