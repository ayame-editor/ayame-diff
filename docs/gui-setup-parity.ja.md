# GUI設定整合性チェックリスト

引退したターミナルウィザードはブラウザのGUIによって完全に表現されています。この表は移行を明示的に記録しており、将来の変更によってインタラクティブな設定が黙って削除されることを防ぎます。

| 旧ウィザード画面 / 設定項目 | GUIコントロール |
|---|---|
| 左右の入力パス | 旧 / 新入力とサーバーサイドファイルブラウザ |
| 出力パス | 比較とパフォーマンスの下の出力パス |
| ヘッダーの有無 | ヘッダ行のチェックボックス |
| 名前 / 位置によるヘッダーの整列 | 名前で整列のチェックボックス |
| 軽量な最初のレコード検査 | ヘッダーの検査; 検出フォーマット、パーサー、並べ替え状態 |
| 全列キー | キーモード：すべての列 |
| 選択したキーを含む | キーモード：選択したキー + 検索可能なチェックボックスグリッド |
| 選択したキーを除外 | キーモード：除外したキー + 検索可能なチェックボックスグリッド |
| 複数選択すべて / 反転 / 範囲 | すべて選択、反転; サーバー/エンジンの検証 |
| 左右のフォーマット | 左フォーマット / 右フォーマット (`auto`, `csv`, `tsv`) |
| 左右のパーサー | 左パーサー / 右パーサー (`auto`, `rfc4180`, `simple`) |
| 左右の区切り文字の上書き | 左区切り文字 / 右区切り文字 |
| Lazy quotes | Lazy quotes チェックボックス |
| 先頭の空白をトリム | 先頭空白トリムのチェックボックス |
| メモリ制限 | メモリ |
| 一時ディレクトリ | 一時ディレクトリ |
| ハッシュパーティション | パーティション |
| 並列入力リーダー | 入力リーダー |
| 比較ワーカー | ワーカー |
| マージファンイン | マージファンイン |
| パーティションバッファ | パーティションバッファ |
| 最大レコードサイズ | 最大レコードサイズ |
| 一時ファイルを保持 | 一時ファイル保持のチェックボックス |
| 進行状況 | ページ内経過タイマーとキャンセルコントロール（端末の進行ストリームなし） |
| 出力ヘッダー | 出力ヘッダーのチェックボックス |
| 実行前のレビュー | 設定確認の開示 |
| エラー回復 | インラインエラーステータス; 設定は保持され編集可能 |
| 開始 / キャンセル | 比較 / 実行とエクスポート / キャンセル |

GUIはまた、ケース・空白・正規表現フィルター、無視値列、グローバルおよび列ごとの数値許容差、セルレベルの出力、表示行制限、TSV対JSON Linesエクスポートも提供します。
